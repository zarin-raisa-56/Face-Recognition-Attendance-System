# Face Recognition Attendance System (Web)

ব্রাউজারেই চলে: ফেস রিকগনিশন, পলক-ভিত্তিক লাইভনেস চেক, দৈনিক রিপোর্ট, শতকরা সামারি ও CSV এক্সপোর্ট।
কোনো সার্ভার লাগে না। ডেটা প্রতিটি ব্রাউজারের IndexedDB-তে সেভ হয়।

ডিফল্ট লগইন: `admin` / `admin123` (লগইনের পর "পাসওয়ার্ড বদলাও" চাপো)।

## GitHub Pages-এ লাইভ করা
1. GitHub-এ নতুন repository বানাও, `index.html` ও এই `README.md` আপলোড করো।
2. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save।
3. ১-২ মিনিট পর `https://<username>.github.io/<repo>/` এ সাইট চালু হবে।
